# （一）Chocolate Giving S

## 题目信息

题目链接：[https://www.luogu.com.cn/problem/P2984](https://www.luogu.com.cn/problem/P2984)

知识点：最短路、Dijkstra、路径拆分

## 题目简述

> 农场里有 `N` 个牧场、`M` 条双向道路，以及 `B` 组“公牛送巧克力”请求。每头公牛需要先从所在牧场走到 `1` 号牧场拿巧克力，再从 `1` 号牧场走到目标母牛所在牧场。
>
> 对于全部数据，`2 * B <= N <= 50000`，`N-1 <= M <= 10^5`，`B <= 25000`，道路长度不超过 `2000`。
>
> 1.00s，125MB。

## 题目分析

### 1. 读题
每个询问看起来都像一条新的最短路：公牛从 `P_i` 出发，到 `1` 号点，再到 `Q_i`。如果对每组询问都单独跑一遍最短路，显然会重复计算很多次。

### 2. 性质观察
题目强制所有路线都必须经过 `1` 号牧场，因此一条合法路线的长度一定是：

`dist(P_i, 1) + dist(1, Q_i)`

又因为图是无向图，所以 `dist(P_i,1) = dist(1,P_i)`。于是只要从 `1` 号点做一次单源最短路，之后每个询问都可以直接用：

`dist[P_i] + dist[Q_i]`

得到答案。

### 3. 程序设计思路
1. 建立无向图邻接表；
2. 从 `1` 号点运行一次 Dijkstra，求出它到所有点的最短距离；
3. 依次读入每组 `(P_i, Q_i)`；
4. 直接输出 `dist[P_i] + dist[Q_i]`；
5. 因为道路长度和结点规模都不小，距离数组最好使用 `long long`。

### 4. 数据结构与算法选择
本题最关键的不是多次最短路，而是发现“所有询问都共享同一个中转点 `1`”。因此最合适的做法是“一次 Dijkstra + 多次 O(1) 回答询问”。

### 5. 时空复杂度分析
- 时间复杂度：$O((N+M)\log N + B)$。
- 空间复杂度：$O(N+M)$。

# （二）出差

## 题目信息

题目链接：[https://www.luogu.com.cn/problem/P8802](https://www.luogu.com.cn/problem/P8802)

知识点：最短路、点权转边、Dijkstra

## 题目简述

> 需要从城市 `1` 赶到城市 `N`。道路有通行时间，此外到达某个中转城市后还需要隔离一段时间，只有城市 `1` 不需要出发前隔离，城市 `N` 到达后也不需要再计算隔离时间。
>
> 对于全部数据，`N <= 1000`，`M <= 10000`，隔离时间 `C_i <= 200`，道路耗时 `c <= 1000`。
>
> 1.00s，128MB。

## 题目分析

### 1. 读题
题目表面是最短路，但路径代价不只来自边权，还来自中转城市的隔离时间。也就是说，这是一道“边权 + 点权”共同参与的最短路问题。

### 2. 性质观察
对于一条路径，总花费等于：
1. 所有经过道路的通行时间之和；
2. 所有中间停留城市的隔离时间之和；
3. 但起点 `1` 不额外加隔离，终点 `N` 到达后也不需要再隔离。

这说明可以把“进入城市 `v` 的代价”改写为：

`道路时间 + C[v]`

其中当 `v = N` 时，不再加 `C[v]`。经过这样转换后，问题就重新变成了标准的非负权最短路。

### 3. 程序设计思路
1. 读入每个城市的隔离时间和所有双向道路；
2. 建立邻接表；
3. 以 `1` 为源点运行 Dijkstra；
4. 从 `u` 松弛到 `v` 时，边代价设为 `w + extra`，其中 `extra = 0` 当且仅当 `v = N`，否则 `extra = C[v]`；
5. 最终输出 `dist[N]`。

### 4. 数据结构与算法选择
本题依旧适合 Dijkstra，因为所有通行时间和隔离时间都非负。关键处理是把点权正确并入转移，而不是改变最短路算法本身。

### 5. 时空复杂度分析
- 时间复杂度：$O((N+M)\log N)$。
- 空间复杂度：$O(N+M)$。
