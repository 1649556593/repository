# Linux 命令与系统管理

## 一、目录与命令基础

### 1. Linux目录结构

Linux没有盘符概念，所有文件都位于根目录`/`之下，路径层级使用`/`分隔。例如`/usr/local/hello.txt`开头的`/`代表根目录。

| 目录 | 作用 |
| --- | --- |
| `/bin` | 常用可执行文件 |
| `/dev` | 设备文件，外接设备通常需要挂载后使用 |
| `/etc` | 系统配置文件 |
| `/home` | 普通用户的家目录 |
| `/proc` | 提供进程和内核运行信息的虚拟文件系统 |
| `/root` | root用户的家目录 |
| `/sbin` | 系统管理相关的可执行文件 |
| `/tmp` | 临时文件 |
| `/usr` | 应用程序、库和共享资源 |
| `/var` | 日志等经常变化的数据 |
| `/mnt` | 常用的临时挂载目录 |

`ls -l`结果的第一个字符表示文件类型：

- `-`普通文件，`d`目录，`l`软链接。
- `c`字符设备，`b`块设备，`p`管道文件，`s`套接字。

### 2. 命令格式与帮助

Linux终端使用字符命令操作系统，通用格式为：

```text
command [options] [parameter]
```

- `command`：命令本身。
- `options`：可选参数，用于控制命令行为。
- `parameter`：可选参数，通常表示操作目标。
- 示例：`ls -l /home/user`以列表形式显示目录内容。

使用`man [卷号] 名称`查看帮助文档：第1卷是命令，第2卷是系统调用，第3卷是库函数，第5卷是文件格式。

### 3. 路径

- 绝对路径：从根目录`/`开始。
- 相对路径：从当前工作目录开始。
- `.`或`./`表示当前目录，`..`或`../`表示上级目录，`~`表示当前用户的HOME目录。
- 示例：`cd ../..`向上两级，`cd ~/Desktop`进入HOME目录下的Desktop。

## 二、文件与目录操作

### 1. 查看和切换目录

| 命令 | 作用 |
| --- | --- |
| `ls [路径]` | 平铺显示目录内容 |
| `ls -a` | 显示全部内容，包括隐藏文件 |
| `ls -l` | 以详细列表形式显示 |
| `ls -lh` | 使用K、M、G等易读单位显示大小 |
| `cd [路径]` | 切换工作目录；不带路径时回到HOME目录 |
| `pwd` | 显示当前工作目录 |

以`.`开头的文件或目录属于隐藏内容。多个`ls`选项可以合并，例如`ls -alh`。

### 2. 创建与查看文件

| 命令 | 作用 |
| --- | --- |
| `mkdir 目录` | 创建目录 |
| `mkdir -p 多级路径` | 递归创建多级目录 |
| `touch 文件` | 创建空文件或更新时间戳 |
| `cat 文件` | 一次显示全部文件内容 |
| `more 文件` | 分页显示文件内容 |
| `tail 文件` | 默认显示文件末尾10行 |
| `tail -n 行数 文件` | 显示文件末尾指定行数 |
| `tail -f 文件` | 持续跟踪文件新增内容，按`Ctrl+C`停止 |

### 3. 复制、移动与删除

| 命令 | 作用 |
| --- | --- |
| `cp 源文件 目标` | 复制文件 |
| `cp -r 源目录 目标` | 递归复制目录 |
| `mv 源 目标` | 移动文件或目录；目标不存在时可用于重命名 |
| `rm 文件` | 删除文件 |
| `rm -r 目录` | 递归删除目录 |
| `rm -f 文件` | 强制删除，不进行提示 |

通配符：`test*`匹配以test开头的名称，`*test`匹配以test结尾的名称，`*test*`匹配包含test的名称。

### 4. 查找文件和内容

| 命令 | 作用 |
| --- | --- |
| `which 命令` | 查看命令对应的程序文件位置 |
| `find 起始路径 -name "名称"` | 按名称查找，名称可使用通配符 |
| `find 起始路径 -size +10M` | 按大小查找；`+`大于，`-`小于，单位可用K、M、G |
| `find 起始路径 -type f` | 按类型查找，如`f`文件、`d`目录、`l`软链接 |
| `find 起始路径 -maxdepth n` | 限制最大搜索深度 |
| `grep [-n] 关键字 文件` | 显示包含关键字的行，`-n`同时显示行号 |

时间条件：`-atime`按访问时间，`-mtime`按内容修改时间，`-ctime`按状态修改时间查找。

对查找结果执行命令：

```bash
find 路径 条件 -exec ls -l {} \;
find 路径 条件 -ok rm -r {} \;
find 路径 条件 -print0 | xargs -0 ls -l
```

- `-exec`直接执行命令，`-ok`会逐项询问。
- `xargs`可以分批处理大量结果；`-print0`与`xargs -0`配合，可正确处理包含空格的文件名。

### 5. 统计、管道与重定向

| 命令或符号 | 作用 |
| --- | --- |
| `wc 文件` | 显示行数、单词数、字节数和文件名 |
| `wc -c` | 统计字节数 |
| `wc -m` | 统计字符数 |
| `wc -l` | 统计行数 |
| `wc -w` | 统计单词数 |
| `命令1 \| 命令2` | 将左侧输出作为右侧输入，可连续使用 |
| `>` | 覆盖写入文件 |
| `>>` | 追加写入文件 |
| `echo 内容` | 在终端输出内容 |

命令替换推荐使用`$(命令)`，例如`echo $(pwd)`；也可以使用反引号形式。

## 四、用户与权限

### 1. root与sudo

root拥有系统最高权限。Ubuntu默认禁用root直接登录，安装时创建的第一个用户通常已经加入`sudo`组。

- `sudo 命令`：以root权限执行一条命令。
- `sudo -i`：进入root shell；`exit`或`Ctrl+D`退出。
- `su - 用户名`：切换用户并加载该用户的环境。
- `sudo usermod -aG sudo 用户名`：将用户加入sudo组，重新登录后生效。
- 配置免密码sudo：执行`sudo visudo -f /etc/sudoers.d/用户名`，加入`用户名 ALL=(ALL) NOPASSWD: ALL`。

### 2. 用户和用户组

以下管理命令通常需要在前面添加`sudo`。

| 命令 | 作用 |
| --- | --- |
| `adduser 用户名` | Ubuntu推荐的用户创建命令，自动创建HOME并引导设置密码 |
| `useradd -m 用户名` | 使用底层命令创建用户和HOME目录 |
| `userdel -r 用户名` | 删除用户及其HOME目录 |
| `groupadd 组名` | 创建用户组 |
| `groupdel 组名` | 删除用户组 |
| `id [用户名]` | 查看用户ID和所属组 |
| `usermod -aG 组名 用户名` | 将用户加入附加组 |
| `getent passwd` | 查看系统用户信息 |

`useradd`的`-g`指定主组，`-d`指定HOME路径，`-m`创建HOME目录。

### 3. 文件权限

`ls -l`最左侧依次显示文件类型、所属用户权限、所属组权限和其他用户权限。每组权限由三个字符组成：

- `r`：读取文件；对目录表示查看内容。
- `w`：修改文件；对目录表示创建、删除或改名。
- `x`：执行文件；对目录表示可以进入。

| 命令 | 作用 |
| --- | --- |
| `chmod u=rwx,g=rx,o=x 文件` | 按用户、组和其他用户设置权限 |
| `chmod 751 文件` | 使用八进制数字设置权限 |
| `chmod -R 权限 目录` | 递归修改目录中的权限 |
| `chown 用户:组 文件` | 修改所属用户和用户组 |
| `chown -R 用户:组 目录` | 递归修改所有者 |

只有文件所有者或root可以修改权限，`chown`通常需要root权限。

`umask`表示创建文件或目录时需要去除的权限。普通文件基础权限为`666`，目录为`777`，去除`umask`中的权限后得到最终权限。

### 4. 链接与inode

- `ln 原文件 新文件`创建硬链接：多个文件名指向同一个inode，不能跨文件系统，通常不能链接目录。
- `ln -s 原文件 新文件`创建软链接：保存目标路径，类似快捷方式，可以跨文件系统并指向目录。

inode保存文件类型、权限、UID、GID、大小、时间戳、硬链接计数和数据块指针，但不保存文件名和实际数据。系统通过目录项将文件名映射到inode编号，再根据inode中的指针读取数据。

- `ls -i`查看inode编号，`stat 文件`查看详细信息，`df -i`查看inode使用情况。
- 硬链接计数归零且文件不再被进程占用时，数据才会释放。
- inode耗尽时，即使磁盘仍有空间，也无法创建新文件。

### 5. 日期、时间和环境变量

`date [-d] [+格式]`用于查看或计算日期，例如`date -d "-1 year -1 day"`和`date +%Y-%m-%d`。

| 格式 | 含义 |
| --- | --- |
| `%Y` / `%y` | 四位年份 / 两位年份 |
| `%m` / `%d` | 月 / 日 |
| `%H` / `%M` / `%S` | 时 / 分 / 秒 |
| `%s` | 从1970-01-01 00:00:00 UTC至今的秒数 |

Ubuntu时间管理：

- `timedatectl status`查看时间和同步状态。
- `sudo timedatectl set-ntp true`开启自动同步。
- `sudo timedatectl set-timezone Asia/Shanghai`设置时区。

环境变量是操作系统运行时记录的键值信息。系统根据`PATH`变量查找可执行程序，使用`$变量名`取值。

- 临时设置：`export 变量名=变量值`。
- 当前用户永久设置：写入`~/.bashrc`。
- 所有用户永久设置：写入`/etc/profile`。
- 立即加载配置：`source 配置文件`。

## 六、网络与进程

### 1. IP、主机名和域名

- `ip addr`或`ip a`查看本机IP。
- `127.0.0.1`表示本机。
- `0.0.0.0`可表示本机所有地址；在访问规则中常表示任意IP。
- `hostname`查看主机名，`sudo hostnamectl set-hostname 主机名`修改主机名。

访问域名时，系统先检查本机hosts文件，再向DNS服务器查询。Windows hosts文件位于`Windows\System32\drivers\etc\hosts`，Linux位于`/etc/hosts`。

### 2. Ubuntu固定IP

Ubuntu Server通常使用Netplan，配置文件位于`/etc/netplan/`。先用`ip a`查看网卡名，再编辑实际的YAML文件：

```yaml
network:
  version: 2
  ethernets:
    ens33:
      dhcp4: false
      addresses:
        - 192.168.10.10/24
      routes:
        - to: default
          via: 192.168.10.2
      nameservers:
        addresses: [8.8.8.8, 114.114.114.114]
```

- 网卡名、IP、网关和DNS需要根据VMware虚拟网络修改，YAML只能使用空格缩进。
- `sudo netplan try`测试配置，`sudo netplan apply`应用配置。
- Ubuntu Desktop通常也可以在系统设置的网络界面中配置固定IP。

### 3. 网络命令与端口

| 命令 | 作用 |
| --- | --- |
| `ping [-c 次数] IP或主机名` | 检查网络连通性 |
| `wget [-b] URL` | 下载文件，`-b`表示后台下载并写入`wget-log` |
| `curl URL` | 发起网络请求或下载内容 |
| `nmap IP` | 扫描目标暴露的端口 |
| `sudo ss -lntup` | 查看本机监听端口和相关进程 |
| `sudo ss -lntup \| grep 端口号` | 查看指定端口占用情况 |

缺少命令时可以安装：`sudo apt install iputils-ping wget curl nmap`。

端口范围：1～1023为公认端口，如SSH 22和HTTPS 443；1024～49151为注册端口；49152～65535通常为动态临时端口。

### 4. 进程管理

程序运行时会被操作系统注册为进程，并分配唯一PID。

| 命令 | 作用 |
| --- | --- |
| `ps -ef` | 显示全部进程的完整信息 |
| `kill PID` | 请求进程正常退出 |
| `kill -9 PID` | 强制结束进程 |

`ps -ef`主要字段：UID为所属用户，PID为进程号，PPID为父进程号，C为CPU占用率，STIME为启动时间，TTY为终端，TIME为CPU时间，CMD为启动命令。

### 5. top系统监控

`top`顶部依次显示系统时间与负载、进程统计、CPU状态、物理内存和交换内存。进程列表常见字段：

| 字段 | 含义 |
| --- | --- |
| `PID` / `USER` | 进程号 / 所属用户 |
| `PR` / `NI` | 优先级 / nice值，数值越小优先级越高 |
| `VIRT` / `RES` / `SHR` | 虚拟内存 / 物理内存 / 共享内存 |
| `S` | 进程状态，如R运行、S休眠、Z僵尸 |
| `%CPU` / `%MEM` | CPU / 内存占用率 |
| `TIME+` | 累计CPU时间 |
| `COMMAND` | 命令或程序名 |

常用选项：`-p PID`只看指定进程，`-d 秒数`设置刷新间隔，`-n 次数`限制刷新次数，`-b`批处理输出，`-u 用户`筛选用户，`-i`隐藏闲置进程。

交互按键：`h`帮助，`c`显示完整命令，`f`选择字段，`M`按内存排序，`P`按CPU排序，`T`按时间排序，`1`切换各CPU信息，`t`切换CPU显示，`m`切换内存显示，`i`隐藏闲置进程。

### 6. 磁盘和网络监控

先安装工具：`sudo apt install sysstat`。

- `df -h`：使用易读单位查看磁盘空间。
- `iostat -x [间隔] [次数]`：查看CPU和磁盘I/O。
- `sar -n DEV [间隔] [次数]`：查看网卡流量。

`iostat`常见字段：`tps`每秒传输次数，`rrqm/s`和`wrqm/s`为合并的读写请求，`rKB/s`和`wKB/s`为每秒读写量，`avgqu-sz`为平均队列长度，`await`为平均I/O等待时间，`%util`为磁盘利用率。

`sar`常见字段：`IFACE`网卡名，`rxpck/s`和`txpck/s`为每秒收发包数，`rxKB/s`和`txKB/s`为每秒收发数据量，`rxcmp/s`和`txcmp/s`为压缩包数量，`rxmcst/s`为接收的多播包数。

## 七、传输与压缩

### 1. 上传下载

FinalShell可以在本机和虚拟机之间拖拽文件。也可以安装lrzsz：`sudo apt install lrzsz`。

- `rz`上传文件，`sz 文件`下载文件。

### 2. tar、gzip和bzip2

- `.tar`只归档文件，通常不明显减小体积。
- `.tar.gz`使用gzip压缩，`.tar.bz2`使用bzip2压缩。
- `tar`常用选项：`-c`创建，`-x`解压，`-v`显示过程，`-f`指定文件，`-z`使用gzip，`-j`使用bzip2，`-C`指定解压目录。

```bash
# gzip压缩和解压
tar -zcvf test.tar.gz file1 dir2
tar -zxvf test.tar.gz -C 目标目录
```

### 3. ZIP和RAR

安装ZIP工具：`sudo apt install zip unzip`。

| 格式 | 压缩 | 解压 |
| --- | --- | --- |
| ZIP | `zip -r 压缩包.zip 文件或目录` | `unzip 压缩包.zip -d 目标目录` |
| RAR | `rar a -r 压缩包.rar 目录` | `unrar x 压缩包.rar` |
