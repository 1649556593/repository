## 第二章

### 01-Linux目录结构

- Linux没有盘的概念只有一个根目录 `/`，所有文件都在这下面。
- Linux系统中路径之间的层级关系使用 `/` 表示。
- eg: `/usr/local/hello.txt`
  - 开头的 `/` 表示根目录。
  - 后面的表示层级关系。
常见目录：

- `/bin`：存放常用的可执行文件。
- `/dev`：存放设备文件，外接设备通常需要挂载后使用。
- `/etc`：存放系统配置文件。
- `/home`：普通用户的家目录。
- `/proc`：提供进程和内核运行信息的虚拟文件系统。
- `/root`：root用户的家目录。
- `/sbin`：存放系统管理相关的可执行文件。
- `/tmp`：存放临时文件。
- `/usr`：存放应用程序、库和共享资源。
- `/var`：存放日志等经常变化的数据。
- `/mnt`：常用的临时挂载目录。

常见文件类型（`ls -l`结果的第一个字符）：

- `-`：普通文件；`d`：目录；`l`：软链接。
- `c`：字符设备；`b`：块设备。
- `p`：管道文件；`s`：套接字。

### 02-Linux命令基础

- 命令行：Linux终端（terminal），以纯字符的形式操作系统，用各种字符化命令对系统发出操作指令。
- 命令：Linux程序，一个命令就是一个Linux程序，命令没有图形化页面，可以在命令行中提供字符化反馈。

**通用格式**

```bash
command -options parameter
```

- `command`：命令本身。
- `-options`：[可选，非必填] 命令的一些选项，可以通过选项控制命令的行为细节。
- `parameter`：[可选，非必填] 命令的参数，多数用于命令的指向目标。
- eg: `ls -l /home/itheima` 以列表形式展示根目录下 `home/itheima` 文件夹内容。

使用`man`查看帮助文档：`man [卷号] 名称`。

- 第1卷：命令；第2卷：系统调用；第3卷：库函数；第5卷：文件存储格式。

### 03-Linux命令入门

**`ls [-a -l -h] [linux路径]`**

- 不使用选项和参数，直接用 `ls` 命令本体表示：以平铺形式列出当前工作目录（默认HOME目录）下的内容。
- `-a` 表示列出全部文件（包含隐藏的文件/文件夹）。
- 以 `.` 开头的表示的是Linux系统隐藏文件/文件夹。
- `-l` 表示以列表的形式展示内容并展示更多信息。
- `-l -a -la -al` 都表示同时应用选项 `-a` 和 `-l`。
- `-h` 表示以易于阅读的形式列出文件大小如K，M，G，`-h` 选项必须要搭配 `-l` 一起用。

**`cd` 切换工作目录**

```bash
cd [Linux路径]
```

- `cd` 命令无需选项，只有参数，表示要切换到哪个目录下。
- `cd` 命令不写参数表示回到用户的HOME目录。

**`pwd` 查看当前工作目录**

- 无选项无参数。

### 04-相对路径、绝对路径、特殊路径符号

- 相对路径：以当前目录为起点，相对于目前路径的子文件或者子文件夹。
- 绝对路径：以根目录为起点。

**特殊路径**

- `.` 表示当前目录，比如 `cd ./Desktop` 表示切换到当前目录下的Desktop目录。
- `..` 表示上一级目录：`cd ..`切换到上一级目录，`cd ../..`切换到上两级目录。
- `~` 表示HOME目录，比如`cd ~`切换到HOME目录，`cd ~/Desktop`切换到HOME目录下的Desktop。

### 05-mkdir命令

Make Directory 创建新的目录（文件夹）。

```bash
mkdir [Linux路径]
mkdir -p [Linux路径]
```

- 参数必填，表示Linux路径，即要创建的文件夹的路径，相对路径或绝对路径都可以。
- `mkdir [Linux路径]`
- `mkdir -p [Linux路径]` 多层级创建文件。

### 06-touch、cat、more命令

**`touch [Linux]` 命令**

- 创建文件，`touch` 命令无选项，参数必填，表示要创建的文件路径，相对绝对特殊路径都可以使用。

**`cat [Linux]` 命令**

- 查看文件中的内容，全部显示。

**`more [Linux]` 命令**

- 查看文件内容，支持翻页，如果内容过多可以一页一页展示。

### 07-cp、mv、rm命令

**`cp [-r] 参数1，参数2`**

- `-r` 命令可选，用于复制文件夹使用，表示递归。
- 参数1，Linux路径，表示被复制的文件或者文件夹。
- 参数2，Linux路径，表示要复制去的地方。

**`mv 参数1，参数2`**

- 参数1，Linux路径，表示被移动的文件或者文件夹。
- 参数2，Linux路径，表示要移动去的地方。
- 参数2如果不存在，那么参数2可以作为修改后的名字。

**`rm [-r -f] 参数1 参数2.........参数N`**

- `-r` 用于删除文件夹。
- `-f` 表示force，强制删除（管理员模式 `su - root`，推出 `exit`）。
- 参数表示要删除文件或文件夹的路径。
- `rm` 支持 `通配符`：
  - `test*` 表示匹配任何以test开头的内容。
  - `*test` 表示匹配任何以test结尾的内容。
  - `*test*` 表示匹配任何包含test的内容。
  - 但是只能在目标文件所在文件夹里找，不能通过路径找。

### 08-which、find命令

**`which`**

- 可以通过 `which` 命令查看所使用的命令的程序文件位置。

**`find`**

```bash
find 起始路径 -name "被查找文件名"
find 起始路径 -size +|-n[KMG]
```

- `find 起始路径 -name "被查找文件名"` 也可以使用通配符。
- `find 起始路径 -size +|-n[KMG]`
  - `+ -` 表示大于小于。
  - `n` 表示大小数字。
  - `KMG` 表示单位。
- `-type`：按文件类型搜索。
- `-maxdepth n`：指定最大搜索深度。
- `-atime`：按访问时间搜索；`-mtime`：按内容修改时间搜索；`-ctime`：按状态修改时间搜索。
- `-exec 命令 {} \;`：对每个搜索结果执行命令，例如`find ... -exec ls -l {} \;`。
- `-ok 命令 {} \;`：交互式确认后执行命令，例如`find ... -ok rm -r {} \;`。
- `-print0`：使用空字符分隔结果，适合包含空格的文件名。

将结果交给`xargs`处理：

```bash
find ... | xargs ls -l
find ... -print0 | xargs -0 ls -l
```

`xargs`会分批处理大量结果；`-0`表示按空字符读取，与`find -print0`配合使用。

### 09-grep、wc命令

**`grep`**

从文件中通过关键字过滤文件行（显示有关键字的行）。

```bash
grep [-n] 关键字 文件路径
```

- `-n` 可选，表示在结果中显示匹配行的行号。
- 参数：关键字，必填，带有空格和其他特殊符号建议用 `""` 将关键字包围。
- 参数：文件路径，必填，表示要过滤内容的文件路径可以作为内容输入端口。

**`wc [-c -m -l -w] 文件路径`**

- `-c` 统计bytes数量。
- `-m` 统计字符数量。
- `-l` 统计行数。
- `-w` 统计单词数。
- 什么都不加就是 行数+单词数+字节数+文件名。
- 参数：文件路径，被统计的文件，可作为内容输入端口。

### 10-管道符| 重定向符

**管道符 `|`**

- 将左边命令的输出作为右边命令的输入，允许嵌套使用。

**重定向符**

- `>` 将左侧命令的结果覆盖写道符号右侧指定文件中。
- `>>` 将左侧命令的结果追加写到符号右侧指定的文件中。

### 11-echo ` tail 命令

**`echo`**

在命令行输出指定的内容，无需参数。

```bash
echo 输出的内容
echo `pwd`
```

- 被 `` ` `` 包围的内容将被当作命令执行并输出。

**`tail`**

查看文件尾部内容，跟踪文件的最新修改。


- 参数，Linux路径，表示被追踪的文件路径。
- 选项，`-f` 表示持续跟踪，通过 `ctrl+c` 停止。
- 选项，`-num`，表示查看尾部多少行，不填默认10行。

## 第三章 Linux用户和权限

### 01 root用户

- Linux采用多用户的管理模式进行权限管理。
- Linux系统中拥有最大权限账户名为root。
- Ubuntu默认禁用root账户的直接登录，安装系统时创建的第一个用户通常已经加入`sudo`组。
- 需要root权限时，推荐在命令前使用`sudo`；需要临时进入root shell时使用`sudo -i`。

**`su [-] [用户名]`**

- `-` 符号是可以多选的，表示是否在切换用户之后加载变量环境。
- 参数：用户名，表示要切换的用户。在Ubuntu中切换到root通常使用`sudo -i`。
- 切换用户名之后可以通过 `exit` 命令退回到上一个用户也可以用 `ctrl+d`。

**`sudo`**

- 在其他命令之前带上 `sudo` 可为这一条命令临时赋予root授权。
- 但是需要将普通用户加入`sudo`用户组，安装Ubuntu时创建的第一个用户通常已经完成配置。
- 将用户加入`sudo`组：`sudo usermod -aG sudo 用户名`，重新登录后生效。
- 如需配置免密码sudo，执行`sudo visudo -f /etc/sudoers.d/用户名`，加入：

```bash
用户名 ALL=(ALL) NOPASSWD: ALL
```

- 最后 `wq` 保存。

### 02 用户、用户组

以下命令需要root权限，在Ubuntu中通常在命令前加`sudo`。

- 创建用户组：`groupadd 用户组名`
- 删除用户组：`groupdel 用户组名`
- Ubuntu推荐使用`adduser 用户名`创建用户，它会引导设置密码并自动创建HOME目录。
- 也可以使用底层命令：`useradd -m 用户名`
  - `-m` 创建用户的HOME目录。
  - `-g` 指定用户的主组，指定的用户组需要已经存在。
  - `-d` 指定用户HOME路径，不指定时通常为：`/home/用户名`。
- 删除用户：`userdel [-r] 用户名`
  - `-r` 删除用户的HOME目录，不使用 `-r`，删除用户时HOME目录保留。
- 查看用户
- 查看用户所属组：
  - `id[用户名]`：参数：用户名，被查看的用户如果不提供则查看自身
- 修改用户所属组：
  - `usermod -aG 用户组 用户名`：将指定用户加入指定用户组
  - `getent passwd`：查看当前系统中有哪些用户

### 03 查看权限控制

**查看权限**

- 最左侧表示文件，文件夹的权限控制信息
  - `-`开头表示文件，`d`开头表示文件夹,`l`表示快捷方式
  - 后面的第一部分（三个字符）表示所属用户权限
  - 第二部分为(三个字符)所属用户组权限
  - 第三部分为(三个字符)其他用户权限
    - r针对文件表示读权限，针对文件夹表示可以查看文件夹内容，如ls
    - w针对文件表示表示写权限，针对文件夹可以在文件夹内创建删除改名等
    - x针对文件表示执行权限，针对文件夹表示是否可以更改工作目录到此文件夹，即cd进入
- 数字后第一列然后表示文件，文件夹所属用户
- 数字后第二列表示文件，文件夹所属用户组

**修改权限**

`chmod [-R] 权限 文件或文件夹`

注意：只有文件文件夹的所属用户或者root用户才可以修改

> eg:`chmod u=rwx,g=rx,o=x hello.txt` u表示用户权限，g表示用户组权限，o表示其他用户权限，没写的权限表示-

- -R表示该文件夹内部的所有文件也会应用权限修改
- 还可以用快捷写法修改权限：`chmod 751 hello.txt`。三个数字分别代表用户、用户组和其他用户，数字对应二进制权限位，0表示没有权限，1表示具有对应权限。

**修改文件或文件夹所属于用户与用户组**

`chown -R 用户：用户组 文件或文件夹`

- 该命令普通用户无法使用，只适用于root用户

**umask权限掩码**

`umask`表示创建文件或目录时需要去除的权限。普通文件的基础权限为`666`，目录的基础权限为`777`，去除`umask`中的权限后得到最终权限。掩码通常写成四位八进制数，第一位为前导`0`。

## 第四章 Linux的使用操作

### 01 快捷键

- `ctrl+c`强制退出
- `ctrl+d`退出账户登录，或者退出某些特定程序的专属页面，如Python

- `ctrl+e`跳到命令结尾
- `ctrl+键盘左键`向左跳一个单词
- `ctrl+键盘右键`向右跳一个单词
- `ctrl+l`清屏

### 02 程序安装

Ubuntu使用`apt`管理软件，可以自动处理软件依赖；软件安装包格式为`.deb`。

| 操作 | Ubuntu命令 |
| --- | --- |
| 更新软件源索引 | `sudo apt update` |
| 升级已安装的软件 | `sudo apt upgrade` |
| 安装软件 | `sudo apt install 软件名称` |
| 删除软件 | `sudo apt remove 软件名称` |
| 删除软件及其配置 | `sudo apt purge 软件名称` |
| 搜索软件 | `apt search 软件名称` |
| 清理不再需要的依赖 | `sudo apt autoremove` |

- `apt install`、`apt remove`等修改系统的操作需要使用`sudo`并且需要联网。
- 使用`-y`可以自动确认，例如：`sudo apt install -y 软件名称`。
- 安装本地`.deb`软件包：`sudo apt install ./软件包.deb`，`apt`会同时处理依赖。
- 也可以使用`sudo dpkg -i 软件包.deb`安装，但`dpkg`不会自动解决依赖。

`dpkg`常用命令：

- 安装：`sudo dpkg -i xxx.deb`
- 删除：`sudo dpkg -r 软件包名`
- 连同配置一起删除：`sudo dpkg --purge 软件包名`
- 查看`.deb`软件包信息：`dpkg --info xxx.deb`
- 查看软件包安装的文件：`dpkg -L 软件包名`
- 查看已安装的软件包：`dpkg -l`
- 重新配置软件包：`sudo dpkg-reconfigure 软件包名`

源码安装的一般流程：

```bash
# 解压源码包并进入目录，然后检查环境、生成Makefile
cd 源码目录
./configure

# 编译并安装
make
sudo make install

# 清理编译生成的文件
make distclean
```

### 03 systemctl命令

控制软件（服务）的启动关闭开机自启动

- 系统内置服务均可以被systemctl控制
- 第三方软件如果自动注册了可以被systemctl控制
- 第三方软件如果没有自动注册需要手动注册

`systemctl start | stop |status | enable | disable 服务名`

- start启动stop结束
- status查看状态
- enable开机自启动，disable关闭开机自启

> 除了内置的服务以外，部分第三方软件也可以用systemctl控制

### 04 链接与inode

**软链接与硬链接**

```bash
# 硬链接
ln 原文件 新文件

# 软链接
ln -s 原文件 新文件
```

- 软链接类似Windows快捷方式，保存的是目标路径，可以跨文件系统，也可以指向目录。
- 硬链接是同一个inode的另一个文件名，不能跨文件系统，通常不能链接目录。

**inode**

inode（索引节点）是类Unix/Linux文件系统中描述文件属性和数据位置的数据结构。系统通过inode编号识别文件，文件名则保存在目录项中。

inode保存：

- 文件类型、权限、UID和GID。
- 文件大小以及`atime`、`mtime`、`ctime`时间戳。
- 硬链接计数和数据块指针。

inode不保存文件名和文件实际数据。多个硬链接可以指向同一个inode，只有链接计数归零且文件不再被进程占用时，数据才会被真正释放。文件系统的inode耗尽时，即使磁盘仍有空间也无法创建新文件。

访问文件时，系统先通过目录项找到inode编号，再读取inode信息，最后根据数据块指针读取文件内容。

- `ls -i`：查看inode编号。
- `stat 文件`：查看文件和inode的详细信息。
- `df -i`：查看文件系统的inode使用情况。

### 07 在VMware Workstation中配置Linux系统的固定IP地址

虚拟机IP地址是通过DHCP(动态获取IP地址，即每次重启都会重新获取一次可能会导致IP地址频繁变更)

Ubuntu Server通常使用Netplan配置网络，配置文件位于`/etc/netplan/`目录。

1. 使用`ip a`查看网卡名称，例如`ens33`。
2. 使用`ls /etc/netplan/`查看实际配置文件名。
3. 使用`sudo vim /etc/netplan/配置文件.yaml`编辑配置，示例：

```yaml
network:
  version: 2
  ethernets:
    ens33:
      dhcp4: false
      addresses:
        - 192.168.10.10/24
      routes:
        - to: default
          via: 192.168.10.2
      nameservers:
        addresses:
          - 8.8.8.8
          - 114.114.114.114
```

- `ens33`、IP地址、网关和DNS需要根据VMware虚拟网络的实际配置修改。
- YAML使用空格缩进，不能使用Tab。
- 测试配置：`sudo netplan try`
- 应用配置：`sudo netplan apply`
- Ubuntu Desktop的网络通常由NetworkManager管理，也可以在系统设置的网络界面中配置固定IP。

### 11 压缩和解压缩

**使用tar命令压缩或解压缩tar或gzip文件**

市面上有非常多的压缩格式

- zip格式: Linux、Windows、MacOS, 常用
- 7zip: Windows系统常用
- rar: Windows系统常用
- tar: Linux、MacOS常用
- gzip: Linux、MacOS常用

**使用zip、unzip命令压缩或解压缩zip文件**

如果系统未安装：`sudo apt install zip unzip`

Linux和macOS常用的归档和压缩格式：

- `.tar`：tarball归档文件，只打包文件，通常不会明显减小体积。
- `.tar.gz`：使用gzip算法压缩的tar归档文件。

命令格式：`tar [-c -v -x -f -z -j -C] 文件或目录`

- `-c`创建归档；`-x`解压；`-v`显示处理过程。
- `-f`指定归档文件名；`-z`使用gzip；`-j`使用bzip2。
- `-C`指定解压目录。

常用示例：

```bash
# 使用gzip压缩和解压
tar -zcvf test.tar.gz file1 dir2
tar -zxvf test.tar.gz

# 使用bzip2压缩和解压
tar -jcvf test.tar.bz2 file1 dir2
tar -jxvf test.tar.bz2
```

- 压缩ZIP：`zip [-r] 压缩包.zip 文件或目录`，压缩目录时使用`-r`。
- 解压ZIP：`unzip 压缩包.zip [-d 目标目录]`。

RAR格式：

```bash
rar a -r newdir.rar dir
unrar x newdir.rar
```
