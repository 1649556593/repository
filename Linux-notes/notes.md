## 第二章

### 01-Linux目录结构

- Linux没有盘的概念只有一个根目录 `/`，所有文件都在这下面。
- Linux系统中路径之间的层级关系适用 `/` 表示。
- eg: `/usr/local/hello.txt`
  - 开头的 `/` 表示根目录。
  - 后面的表示层级关系。

### 02-Linux命令基础

- 命令行：Linux终端（terminal），以纯字符的形式操作系统，用各种字符化命令对系统发出操作指令。
- 命令：Linux程序，一个命令就是一个Linux程序，命令没有图形化页面，可以在命令行中提供字符化反馈。

#### 通用格式

```bash
command -options parameter
```

- `command`：命令本身。
- `-options`：[可选，非必填] 命令的一些选项，可以通过选项控制命令的行为细节。
- `parameter`：[可选，非必填] 命令的参数，多数用于命令的指向目标。
- eg: `ls -l /home/itheima` 以列表形式展示根目录下 `home/itheima` 文件夹内容。

### 03-Linux命令入门

#### `ls [-a -l -h] [linux路径]`

- 不使用选项和参数，直接用 `ls` 命令本体表示：以平铺形式列出当前工作目录（默认HOME目录）下的内容。
- `-a` 表示列出全部文件（包含隐藏的文件/文件夹）。
- 以 `.` 开头的表示的是Linux系统隐藏文件/文件夹。
- `-l` 表示以列表的形式展示内容并展示更多信息。
- `-l -a -la -al` 都表示同时应用选项 `-a` 和 `-l`。
- `-h` 表示以易于阅读的形式列出文件大小如K，M，G，`-h` 选项必须要搭配 `-l` 一起用。

#### `cd` 切换工作目录

```bash
cd [Linux路径]
```

- `cd` 命令无需选项，只有参数，表示要切换到哪个目录下。
- `cd` 命令不写参数表示回到用户的HOME目录。

#### `pdw` 查看当前工作目录

- 无选项无参数。

### 04-相对路径、绝对路径、特殊路径符号

- 相对路径：以当前目录为起点，相对于目前路径的子文件或者子文件夹。
- 绝对路径：以根目录为起点。

#### 特殊路径

- `.` 表示当前目录，比如 `cd ./Desktop` 表示切换到当前目录下的Desktop目录。
- `..` 表示上一级目录：`cd ..` 即可切换到上一级目录，`cd../..` 切换到上二级目录。
- `~` 表示home目录，比如 `cd ~` 即可切换到home，`cd~/Desktop` 切换到home里的Desktop。

### 05-mkdir命令

Make Directory 创建新的目录（文件夹）。

```bash
mkdir [Linux路径]
mkdir -p [Linux路径]
```

- 参数必填，表示Linux路径，即要创建的文件夹的路径，相对路径或绝对路径都可以。
- `mkdir [Linux路径]`
- `mkdir -p [Linux路径]` 多层级创建文件。

### 06-touch、cat、more命令

#### `touch [Linux]` 命令

- 创建文件，`touch` 命令无选项，参数必填，表示要创建的文件路径，相对绝对特殊路径都可以使用。

#### `cat [Linux]` 命令

- 查看文件中的内容，全部显示。

#### `more [Linux]` 命令

- 查看文件内容，支持翻页，如果内容过多可以一页一页展示。

### 07-cp、mv、rm命令

#### `cp [-r] 参数1，参数2`

- `-r` 命令可选，用于复制文件夹使用，表示递归。
- 参数1，Linux路径，表示被复制的文件或者文件夹。
- 参数2，Linux路径，表示要复制去的地方。

#### `mv 参数1，参数2`

- 参数1，Linux路径，表示被移动的文件或者文件夹。
- 参数2，Linux路径，表示要移动去的地方。
- 参数2如果不存在，那么参数2可以作为修改后的名字。

#### `rm [-r -f] 参数1 参数2.........参数N`

- `-r` 用于删除文件夹。
- `-f` 表示force，强制删除（管理员模式 `su - root`，推出 `exit`）。
- 参数表示要删除文件或文件夹的路径。
- `rm` 支持 `通配符`：
  - `test*` 表示匹配任何以test开头的内容。
  - `*test` 表示匹配任何以test结尾的内容。
  - `*test*` 表示匹配任何包含test的内容。
  - 但是只能在目标文件所在文件夹里找，不能通过路径找。

### 08-which、find命令

#### `which`

- 可以通过 `which` 命令查看所使用的命令的程序文件位置。

#### `find`

```bash
find 起始路径 -name "被查找文件名"
find 起始路径 -size +|-n[KMG]
```

- `find 起始路径 -name "被查找文件名"` 也可以使用通配符。
- `find 起始路径 -size +|-n[KMG]`
  - `+ -` 表示大于小于。
  - `n` 表示大小数字。
  - `KMG` 表示单位。

### 09-grep、wc命令

#### `grep`

从文件中通过关键字过滤文件行（显示有关键字的行）。

```bash
grep [-n] 关键字 文件路径
```

- `-n` 可选，表示在结果中显示匹配行的行号。
- 参数：关键字，必填，带有空格和其他特殊符号建议用 `""` 将关键字包围。
- 参数：文件路径，必填，表示要过滤内容的文件路径可以作为内容输入端口。

#### `wc [-c -m -l -w] 文件路径`

- `-c` 统计bytes数量。
- `-m` 统计字符数量。
- `-l` 统计行数。
- `-w` 统计单词数。
- 什么都不加就是 行数+单词数+字节数+文件名。
- 参数：文件路径，被统计的文件，可作为内容输入端口。

### 10-管道符| 重定向符

#### 管道符 `|`

- 将左边命令的输出作为右边命令的输入，允许嵌套使用。

#### 重定向符

- `>` 将左侧命令的结果覆盖写道符号右侧指定文件中。
- `>>` 将左侧命令的结果追加写到符号右侧指定的文件中。

### 11-echo ` tail 命令

#### `echo`

在命令行输出指定的内容，无需参数。

```bash
echo 输出的内容
echo `pwd`
```

- 被 `` ` `` 包围的内容将被当作命令执行并输出。

#### `tail`

查看文件尾部内容，跟踪文件的最新修改。

```bash
tail [-f -num] Linux路径
```

- 参数，Linux路径，表示被追踪的文件路径。
- 选项，`-f` 表示持续跟踪，通过 `ctrl+c` 停止。
- 选项，`-num`，表示查看尾部多少行，不填默认10行。

## 第三章 Linux用户和权限

### 01 root用户

- Linux采用多用户的管理模式进行权限管理。
- Linux系统中拥有最大权限账户名为root。

#### `su [-] [用户名]`

- `-` 符号是可以多选的，表示是否在切换用户之后加载变量环境。
- 参数：用户名，表示要切换的用户，用户名也可以省略，省略表示要切到root。
- 切换用户名之后可以通过 `exit` 命令退回到上一个用户也可以用 `ctrl+d`。

#### `sudo`

- 在其他命令之前带上 `sudo` 可为这一条命令临时赋予root授权。
- 但是需要为普通用户配置sudo认证。
- 认证方法：切换root用户，执行 `visudo` 命令会自动通过vi编辑器打开：`/etc/sudoers`。
- 文件最后加：

```bash
baijiahui1 ALL=(ALL) NOPASSWORD: ALL
```

- 最后 `wq` 保存。

### 02 用户、用户组

以下命令需要root用户执行。

- 创建用户组：`groupadd 用户组名`
- 删除用户组：`groupdel 用户组名`
- 创建用户：`useradd 用户名 -g 用户组名 -d HOME路径`
  - `-g` 指定用户的组，不指定 `-g` 会创建同名组并自动加入，指定 `-g` 需要组已经存在，如果存在同名组必须使用 `-g`。
  - `-d` 指定用户HOME路径，不指定，HOME目录默认在：`/home/用户名`。
- 删除用户：`userdel [-r] 用户名`
  - `-r` 删除用户的HOME目录，不使用 `-r`，删除用户时HOME目录保留。
- 查看用户
- 查看用户所属组：
  - `id[用户名]`：参数：用户名，被查看的用户如果不提供则查看自身
- 修改用户所属组：
  - `usermod -aG 用户组 用户名`：将指定用户假如指定用户组
  - `getent passwd`：查看当前系统中有哪些用户

### 03 查看权限控制

#### 查看权限

- 最左侧表示文件，文件夹的权限控制信息
  - `-`开头表示文件，`d`开头表示文件夹,`l`表示快捷方式
  - 后面的第一部分（三个字符）表示所属用户权限
  - 第二部分为(三个字符)所属用户组权限
  - 第三部分为(三个字符)其他用户权限
    - r针对文件表示读权限，针对文件夹表示可以查看文件夹内容，如ls
    - w针对文件表示表示写权限，针对文件夹可以在文件夹内创建删除改名等
    - x针对文件表示执行权限，针对文件夹表示是否可以更改工作目录到此文件夹，即cd进入
- 数字后第一列然后表示文件，文件夹所属用户
- 数字后第二列表示文件，文件夹所属用户组

#### 修改权限

`chmod [-R] 权限 文件或文件夹`

注意：只有文件文件夹的所属用户或者root用户才可以修改

> eg:`chmod u=rwx,g=rx,o=x hello.txt` u表示用户权限，g表示用户组权限，o表示其他用户权限，没写的权限表示-

- -R表示该文件夹内部的所有文件也会应用权限修改
- 还可以用快捷写法修改权限`chmod 751 hello.txt`三个数字分别代表用户，用户组和其他用户，数字代表的是二进制，二进制为0就是-，为1就是对应的子母

#### 修改文件或文件夹所属于用户与用户组

`chown -R 用户：用户组 文件或文件夹`

- 该命令普通用户无法使用，只适用于root用户

## 第四章 Linux的使用操作

### 01 快捷键

- `ctrl+c`强制退出
- `ctrl+d`推出账户登录，或者推出某些特定程序的专属页面eg:python
- `history`查看历史命令
- `!+命令`自动执行上次与该命令相同的命令
- `!+字母`自动执行上次以该字母开头的命令
- `ctrl+r`自动搜索上次以该字母开头的命令
- `ctrl+a`跳到命令开头
- `ctrl+e`跳到命令结尾
- `ctrl+键盘左键`向左跳一个单词
- `ctrl+a`向右跳一个单词
- `ctrl+l`清屏

### 02 程序安装

`yum`自动化安装配置Linux软件并可以自动解决依赖问题

`yum [-y] [install | remove | search] 软件名称`

- yum命令需要root权限或sudo提权，需要联网
- centOS：.rpm软件安装包，yum自动安装器(yum软件仓库里面存放了打包好的软件安装包)
- Ubuntu：.deb软件安装包，apt自动安装器

### 03 systemctl命令

控制软件（服务）的启动关闭开机自启动

- 系统内置服务均可以被systemctl控制
- 第三方软件如果自动注册了可以被systemctl控制
- 第三方软件如果没有自动注册需要手动注册

`systemctl start | stop |status | enable | disable 服务名`

- start启动stop结束
- status查看状态
- enable开机自启动，disable关闭开机自启

> 除了内置的服务以外，部分第三方软件也可以用systemctl控制

### 04 软链接

在系统中创建软链接可以将文件、文件夹链接到其它位置

类似windows中的《快捷方式》

`ln -s 参数1 参数2`

- -s创建软链接
- 参数1被链接的文件
- 参数2要链接去的目的地

### 05 日期和时区

#### date命令可以在命令行中查看系统的时间

`date [-d] [+格式化字符串]`

- -d按照给定的字符串显示日期，一般用于日期计算
- eg:date -d "-1 year -1 day"
- 格式化字符串：通过特定的字符串标记来控制显示的日期格式
- eg:date +%Y-%m-%d

| 格式 | 含义 |
| --- | --- |
| %Y | 年 |
| %y | 年份后两位数字 <00,99> |
| %m | 月份 <01,12> |
| %d | 日 <01,31> |
| %H | 小时 <00,23> |
| %M | 分钟 <00,59> |
| %S | 秒 <00,60> |
| %s | 自 1970-01-01 00:00:00 UTC 到现在的秒数 |

也可以通过ntp程序自动校准系统时间

也可手动校准 ntpdate -u ntp.aliyun.com

#### ping命令

`ping [-c num] ip或主机名`

- -c 检查的次数，不使用将无限次数持续检查

#### wget命令

`wget [-b] url`

- -b可选，后台下载，会将日志写入到当前文件工作目录的wget-log文件

#### curl命令

- 向cip.cc发起网络请求，curl cip.cc

#### 端口

IP地址只能锁定计算机，但是无法锁定具体的程序，通过端口可以锁定计算机上具体的程序确保程序之间进行沟通

Linux系统是一个超大号小区, 可以支持65535个端口, 这6万多个端口分为3类进行使用:

- 公认端口:1~1023, 通常用于一些系统内置或知名程序的预留使用, 如SSH服务的22端口, HTTPS服务的443端口
  - 非特殊需要, 不要占用这个范围的端口
- 注册端口:1024~49151, 通常可以随意使用, 用于松散的绑定一些程序\服务
- 动态端口:49152~65535, 通常不会固定绑定程序, 而是当程序对外进行网络链接时, 用于临时使用。

`nmap IP`指令可以查看对应ip地址对外暴露端口

`netstat -anp | grep 端口号`可以查看指定端口占用情况

#### 进程管理

程序运行在操作系统中，是被操作系统所管理的，为管理运行的程序，每一个程序在运行的时候，便被操作系统注册为系统中的一个进程并会为每一个进程都分配一个独有的：进程id(进程号)

`ps [-e -f]`

- -e,显示出全部的进程
- -f,已完全格式化的形式展示信息（展示全部信息）
- 一般直接固定用法 ps -ef

从左到右依次为：

| 字段 | 含义 |
| --- | --- |
| UID | 进程所属用户ID |
| PID | 进程的进程号ID |
| PPID | 进程的父ID |
| C | 此进程的CPU占用率 |
| STIME | 进程的启动时间 |
| TTY | 启动此进程的终端符号 |
| TIME | 进程占用CPU的时间 |
| CMD | 进程对应的启动命令或者启动路径 |

`kill [-9] 进程ID`

- 选项-9表示强制关闭进程。不适用此选项会向进程发送信号要求关闭，但是否关闭取决于程序

#### 主机状态

`top`命令

- 第一行：top -系统时间，up -启动时间 ，users -几个用户登录，load -1，5，15分钟平均负载
- 第二行：Tasks -一共多少进程，running -几个子进程在运行，sleeping -几个进程睡眠，stopped -几个进程停止，zomibe -几个僵尸进程
- 第三行：Cpu(s) -CPU使用率，sy -系统CPU使用率，ni -高优先级进程占用CPU时间比，id -空闲CPU率，wa -IO等待CPU占用率，hi -CPU硬件中断率，si -CPU软件中断率，st -强制等待占用CPU率
- 第四行：Kib Mem：物理内存，total：总量，free：空闲，used：使用，buff/cache：buff和cache占用
- 第五行：KibSwap：虚拟内存，total：总量，free：空闲，used：使用，buff/cache：buff和cache占用

```text
PID USER      PR  NI    VIRT    RES    SHR S %CPU %MEM     TIME+ COMMAND
```

| 字段 | 含义 |
| --- | --- |
| PID | 进程id |
| USER | 进程所属用户 |
| PR | 进程优先级, 越小越高 |
| NI | 负值表示高优先级, 正值表示低优先级 |
| VIRT | 进程使用虚拟内存, 单位KB |
| RES | 进程使用物理内存, 单位KB |
| SHR | 进程使用共享内存, 单位KB |
| S | 进程状态 (S休眠, R运行, Z僵死状态, N负数优先级, I空闲状态) |
| %CPU | 进程占用CPU率 |
| %MEM | 进程占用内存率 |
| TIME+ | 进程使用CPU时间总计, 单位10毫秒 |
| COMMAND | 进程的命令或名称或程序文件路径 |

| 选项 | 功能 |

### 09 环境变量

> 环境变量是操作系统在运行的时候记录的一些关键性信息，用以辅助系统运行，在Linux系统中执行：env命令可以查看当前系统中记录的环境变量
>
> 环境变量是一种KeyValue型结构，即名称和值

在任何位置都可以执行特定程序是因为环境变量中存储了搜索路径，可以直接沿着这些路径寻找需要执行的程序

#### $符号

在linux系统中$符号用于取变量的值

环境变量记录的信息，除了给操作系统自己使用以外，如果我们想取用也可使用

取得环境变量的值就可以通过`$环境变量名`来获取

#### 自行设置环境变量

Linux环境变量可以用户自己设置

- 临时设置，语法：`export 变量名=变量值`
- 永久生效
  - 针对当前用户生效，配置在当前用户的 ~/bashrc文件中
  - 针对所有用户生效，配置在系统的    /etc/profile文件中（全局的，任何用户都有）
  - 并通过语法：`source 配置文件`，进行立刻生效，或重新登陆FinalShell生效

### 11 压缩和解压缩

#### 使用tar命令压缩或解压缩tar或gzip文件

市面上有非常多的压缩格式

- zip格式: Linux、Windows、MacOS, 常用
- 7zip: Windows系统常用
- rar: Windows系统常用
- tar: Linux、MacOS常用
- gzip: Linux、MacOS常用

#### 使用zip、unzip命令压缩或解压缩zip文件
Linux和Mac系统常用有两种压缩格式，后缀名分别是:
.tar，称之为tarball，归档文件，即简单的将文件组装到一个.tar的文件夹内，并没有太多文件体积减少，仅仅是简单的封装
.gz，也常见为.tar.gz，gzip格式压缩文件，即使用gzip压缩算法将文件压缩到一个文件内，可以极大减少压缩后的体积
`tar [-c -v -x -f -z -C] 参数1 参数2 .... 参数N`
- -c, 创建压缩文件，用于压缩模式
- -v, 显示压缩、解压过程，用于查看进度
- -x, 解压模式
- -f, 要创建的文件，或要解压的文件，-f选项必须在所有选项中位置处于最后一个
- -z, -z, gzip模式，不使用-z就是普通的tarball格式
- -C, 选择解压的目的地，用于解压模式
>一般有固定格式 `tar -cvf`压缩 `tar -xvf 解压文件 -C 解压至指定的目录` ,如果要解压成gzip文件就要带-z
`zip [-r] 参数1 参数2 参数N `
- -r被压缩的包含文件夹的时候，需要使用-r选项，和rm，cp等一致
`unzip [-d] 参数` 解压zip压缩包
