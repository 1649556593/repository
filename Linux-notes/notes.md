## 第二章 
### 01-Linux目录结构
Linux没有盘的概念只有一个根目录`/`，所有文件都在这下面
Linux系统中路径之间的层级关系适用 `/` 表示
eg:/usr/local/hello.txt,开头的/表示根目录，后面的表示层级关系

### 02-Linux命令基础
命令行：Linux终端（terminal），以纯字符的形式操作系统，用各种字符化命令对系统发出操作指令
命令：Linux程序，一个命令就是一个Linux程序，命令没有图形化页面，可以在命令行中提供字符化反馈
#### 通用格式：
command：命令本身
-options：[可选，非必填]命令的一些选项，可以通过选项控制命令的行为细节
parameter:[可选，非必填]命令的参数，多数用于命令的指向目标
eg: ls -l /home/itheima 以列表形式展示根目录下home/itheima文件夹内容

### 03-Linux命令入门
#### ls [-a -l -h] [linux路径]
不使用选项和参数，直接用ls命令本体表示：以平铺形式列出当前工作目录（默认HOME目录）下的内容 
`-a` 表示列出全部文件（包含隐藏的文件/文件夹）
以.开头的表示的是Linux系统隐藏文件/文件夹
`-l` 表示以列表的形式展示内容并展示更多信息
`-l -a -la -al` 都表示同时应用选项-a和-l
`-h` 表示以易于阅读的形式列出文件大小如K，M，G，-h选项必须要搭配 -l一起用
#### cd 切换工作目录
cd [Linux路径]
cd命令无需选项，只有参数，表示要切换到哪个目录下
cd命令不写参数表示回到用户的HOME目录
#### pdw 查看当前工作目录
无选项无参数

### 04-相对路径、绝对路径、特殊路径符号
相对路径：以当前目录为起点，相对于目前路径的子文件或者子文件夹
绝对路径：以根目录为起点
特殊路径：
. 表示当前目录，比如cd ./Desktop表示切换到当前目录下的Desktop目录
..表示上一级目录：cd ..即可切换到上一级目录 cd../..切换到上二级目录
~ 表示home目录，比如cd ~即可切换到home， cd~/Desktop切换到home里的Desktop


### 05-mkdir命令
Make Directory 创建新的目录（文件夹）
参数必填 表示Linux路径，即要创建的文件夹的路径，相对路径或绝对路径都可以
mkdir [Linux路径] 
mkdir -p [Linux路径] 多层级创建文件

### 06-touch、cat、more命令
touch [Linux]命令
创建文件，touch命令无选项，参数必填，表示要创建的文件路径，相对绝对特殊路径都可以使用
cat [Linux]命令
查看文件中的内容，全部显示
more [Linux]命令
查看文件内容，支持翻页，如果内容过多可以一页一页展示

### 07-cp、mv、rm命令
cp [-r] 参数1，参数2
-r命令可选，用于复制文件夹使用，表示递归
参数1，Linux路径，表示被复制的文件或者文件夹
参数2，Linux路径，表示要复制去的地方
mv 参数1，参数2
参数1，Linux路径，表示被移动的文件或者文件夹
参数2，Linux路径，表示要移动去的地方
参数2如果不存在，那么参数2可以作为修改后的名字
rm [-r -f] 参数1 参数2.........参数N
-r用于删除文件夹
-f表示force，强制删除（管理员模式su - root，推出exit）
参数表示要删除文件或文件夹的路径
rm支持`通配符`：test*表示匹配任何以test开头的内容，*test表示匹配任何以test结尾的内容，*test*表示匹配任何包含test的内容，但是只能在目标文件所在文件夹里找，不能通过路径找

### 08-which、find命令
which 可以通过which命令查看所使用的命令的程序文件位置
find :
find 起始路径 -name "被查找文件名" 也可以使用通配符
find 起始路径 -size +|-n[KMG]  +-表示大于小于，n表示大小数字，KMG表示单位

### 09-grep、wc命令
grep：从文件中通过关键字过滤文件行（显示有关键字的行）
grep [-n] 关键字 文件路径
-n 可选 表示在结果中显示匹配行的行号
参数 关键字 必填，带有空格和其他特殊符号建议用""将关键字包围
参数 文件路径 必填 表示要过滤内容的文件路径可以作为内容输入端口
wc [-c -m -l -w] 文件路径
-c 统计bytes数量
-m 统计字符数量
-l 统计行数
-w 统计单词数
什么都不加就是 行数+单词数+字节数+文件名
参数 文件路径 被统计的文件 可作为内容输入端口

### 10-管道符| 重定向符
将左边命令的输出作为右边命令的输入，允许嵌套使用
重定向符：
`>` 将左侧命令的结果覆盖写道符号右侧指定文件中 
`>>`将左侧命令的结果追加写到符号右侧指定的文件中

### 11-echo ` tail 命令
echo：在命令行输出指定的内容，无需参数
echo 输出的内容
echo `pwd`, 被`包围的内容将被当作命令执行并输出
tail：查看文件尾部内容，跟踪文件的最新修改
tail [-f -num] Linux路径
参数，Linux路径，表示被追踪的文件路径
选项，-f表示持续跟踪，通过ctrl+c停止
选项，-num，表示查看尾部多少行，不填默认10行

### 12-vi\vim编译器（visual interface）
命令模式，所敲的按键编译器都理解为命令，以命令驱动执行不同的功能，dd快速删除整行，u撤销指令，yyp复制一行
>i 在当前光标进入输入模式
>a 在当前光标位置之后进入输入模式
>I 在当前行的开头进入输入模式
>A 在当前行的结尾进入输入模式
>o 在当前光标下一行进入输入模式
>O 在当前光标上一行进入输入模式
>0 光标放到开头
>$ 光标放到当前行的结尾
>pgup 向上翻页
>pgdn 向下翻页
>/ 进入搜索模式
>n 向下继续搜索
>N 向上继续搜索
>esc 任何情况下输入esc都可以回到命令模式
>dd	删除光标所在行的内容
>ndd n是数字，表示删除当前光标向下n行
>yy	复制当前行
>nyy n是数字，复制当前行和下面的n行
>p 粘贴复制的内容
>u 撤销修改
>ctrl + r 反向撤销修改
>gg	跳到首行
>G	跳到行尾
>dG	从当前行开始，向下全部删除
>dgg 从当前行开始，向上全部删除
>d $ 从当前光标开始，删除到本行的结尾
>d0	从当前光标开始，删除到本行的开头
输入模式，编辑模式，插入模式，此模式下可以对文件对容进行自由编辑
底线模式，通常用于文件的保存和退出,vim [文件路径]，进入命令模式，按`i`进入输入模式，`esc`回到命令模式，`:`进入底线模式，`enter`回到命令模式，进入底线模式后`wq`保存并退出
>wq	保存并退出
>q	仅退出
>q!	强制退出
>w	仅保存
>set nu	显示行号
>set paste	设置粘贴模式
